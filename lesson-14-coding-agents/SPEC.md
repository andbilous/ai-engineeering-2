# TokenBudget: специфікація

Команда з трьома AI-проєктами платить за LLM-API одним рахунком. Наприкінці місяця з'ясовується, що прогони evals з'їли половину бюджету, а хто і на якій моделі, ніхто не знає: ключ спільний, рахунок один. Потрібен внутрішній сервіс, куди кожен виклик моделі записується з токенами, а сервіс сам рахує вартість, веде місячний бюджет проєкту і зупиняє виклики, коли бюджет вичерпано.

Моделі й ціни вигадані. Користувачі в `data/users.json`, проєкти в `data/projects.json`, ціни в `data/prices.json` (долари за 1 млн токенів).

## Бізнес-правила

| # | Правило |
| --- | --- |
| R1 | Вартість виклику = (вхідні − кешовані) × ціна input + кешовані × ціна cached_input + вихідні × ціна output, усе поділене на 1 000 000. `cached_input_tokens` необов'язкове, типово 0 |
| R2 | Кількість токенів не може бути від'ємною, а кешованих не може бути більше, ніж вхідних (`BAD_TOKENS`). Модель має бути в прайсі (`UNKNOWN_MODEL`) |
| R3 | Записувати виклики, бачити виклики й бюджет проєкту можуть лише його учасники: власник (`owner`) і `members` |
| R4 | Витрати рахуються за календарний місяць за датою виклику. Новий місяць починається з нуля, старі виклики лишаються в історії |
| R5 | Статус бюджету: `ok` до 80 %, `warning` від 80 %, `exceeded` від 100 % |
| R6 | Жорсткий ліміт (`hard_limit: true`): виклик, після якого витрати стануть більшими за бюджет, відхиляється (`BUDGET_EXCEEDED`). Рівно бюджет дозволено. М'який ліміт: виклик записується з `over_budget: true` |
| R7 | Бюджет і тип ліміту змінює лише власник проєкту. Бюджет має бути більшим за нуль (`BAD_BUDGET`) |
| R8 | Відхилений виклик не змінює нічого: ні історії, ні витрат |
| R9 | Вхід імітовано: користувач приходить у заголовку `X-User`. Немає заголовка або такого користувача — `401` |

## Технічні рамки

Python 3.12, FastAPI, SQLite. Модуль `app/main.py` має функцію `create_app(db_path: str, today=date.today) -> FastAPI`. Тести передають у неї тимчасову базу і власний «годинник» `today`, тому весь код, якому потрібна сьогоднішня дата, бере її лише з `today()`. Вартість зберігається з точністю до шести знаків після коми. Фронтенд будь-який, але без кроку збирання: сервер віддає його сам на `/`.

## API

Помилка бізнес-правила повертається як `422` з тілом:

```json
{"detail": {"code": "BUDGET_EXCEEDED", "message": "Бюджет $5.00: витрачено $4.00, виклик коштує $1.50"}}
```

Коди: `BAD_TOKENS`, `UNKNOWN_MODEL`, `BUDGET_EXCEEDED`, `BAD_BUDGET`. Не учасник чи не власник — `403`, немає проєкту — `404`.

Виклик у відповідях:

```json
{"id": 1, "project": "eval-runs", "model": "nova-pro", "user": "olivia",
 "input_tokens": 0, "cached_input_tokens": 0, "output_tokens": 400000,
 "cost": 4.0, "created_at": "2026-11-26", "over_budget": false}
```

### Обов'язкові ендпоінти (фічі 1–4)

| Метод і шлях | Хто | Що робить |
| --- | --- | --- |
| `GET /` | усі | сторінка застосунку |
| `GET /api/models` | усі | прайс: `[{"model", "input", "cached_input", "output"}]` |
| `GET /api/projects` | користувач | проєкти, де він власник чи учасник: `id`, `name`, `owner`, `members`, `monthly_budget`, `hard_limit` |
| `POST /api/calls` `{"project", "model", "input_tokens", "output_tokens", "cached_input_tokens"?}` | учасник | записує виклик, `201`; або `422` з кодом |
| `GET /api/projects/{id}/calls` | учасник | усі виклики проєкту, від старих до нових |
| `GET /api/projects/{id}/budget` | учасник | `{"month": "2026-11", "budget", "spent", "remaining", "percent", "status"}` за поточний місяць; `percent` від 0 до 100 і більше, `remaining` за м'якого ліміту може бути від'ємним |
| `PUT /api/projects/{id}/budget` `{"monthly_budget", "hard_limit"}` | власник | змінює бюджет; повертає проєкт |

### Опціональні ендпоінти (фічі 5–7)

| Метод і шлях | Хто | Що робить |
| --- | --- | --- |
| `GET /api/projects/{id}/report.csv?month=YYYY-MM` | учасник | CSV `model,calls,input_tokens,output_tokens,cost`, рядки за моделлю за абеткою, вартість з чотирма знаками |
| `GET /api/models?date=YYYY-MM-DD` | усі | прайс на дату з урахуванням `data/price_changes.json`; вартість виклику рахується за ціною на день виклику і потім не змінюється |
| `GET /api/projects/{id}/forecast` | учасник | `{"month", "spent", "projected", "will_exceed"}`: `projected` = витрачено ÷ номер дня × днів у місяці |
